## 你好，世界！

欢迎来到我的个人网站。这是我用 **Next.js** + **Tailwind CSS** + **TypeScript** 搭建的第一篇文章。

## 为什么建这个网站？

我一直想有一个属于自己的空间，用来：

- 📝 记录技术学习与思考
- 🎥 分享视频创作
- 💡 沉淀知识体系
- 🤝 连接志同道合的朋友

## 技术栈

这个网站使用了以下技术：

| 技术 | 用途 |
|------|------|
| **Next.js 16** | React 全栈框架，支持 SSG/SSR |
| **TypeScript** | 类型安全 |
| **Tailwind CSS v4** | 原子化 CSS 框架 |
| **next-themes** | 暗色模式支持 |
| **gray-matter** | Markdown Frontmatter 解析 |
| **react-markdown** | Markdown 渲染 |
