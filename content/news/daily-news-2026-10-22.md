## 一、AI 行业动态

**DeepSeek 完成约 1000 亿元融资，创下中国 AI 融资纪录（10.22）**

据彭博社报道，DeepSeek 最新一轮融资已筹集约 1000 亿元人民币（约 150 亿美元），宁德时代与腾讯位列最大投资方；融资目标在接洽期间至少两次上调，从最初 500 亿元提到 800 亿元，最终定在 1000 亿元。CEO 梁文锋在近期投资者会议上披露，公司年化营收运行率已突破 10 亿美元，较数月前不足 5 亿美元翻了一倍多，且 API 提价后客户并未流失。这笔钱将投向 AI 数据中心、更多开源模型，并为科创板 IPO 铺路。中国 AI 公司第一次在融资量级上，敢跟硅谷同台叫价了。

**英伟达 GTC 柏林：Vera Rubin 全面量产，AI 工厂 14 天交付（10.21）**

柏林 GTC 舞台上，黄仁勋单手举起一台 128GB 内存的 RTX Spark 轻薄本——2016 年他送到 OpenAI 办公室、同样 128GB 内存的 DGX-1，得两个人抬上楼。他的账是：十年间 AI 性能涨了约 100 万倍，同期摩尔定律只涨了约 100 倍，差的那一万倍来自"极致协同设计"。新发布的 DSX POD 把 7 个液冷机架、约 17 公里线缆在工厂里预集成进集装箱，场地水电就绪后部署从约 6 个月压到最快 14 天；Vera Rubin 单机柜 72 张 GPU，组装一台不到 5 分钟（上代要 2 小时），Agent 负载下每兆瓦吞吐是 Blackwell 的 30 倍。

**Anthropic 招股书曝光：半年营收 163 亿美元，GAAP 净亏 807 亿（10.22）**

Anthropic 招股书草案显示，2026 年上半年营收 163 亿美元，同比增长接近 15 倍；GAAP 净亏损高达 807 亿美元，其中约 720 亿来自可转债等的公允价值调整。公司拟以 2 万亿美元估值上市，未来算力承诺最高达 7500 亿美元。营收涨 15 倍与"巨亏"同时出现，说明这一行的成本曲线跟收入曲线一样陡。

> 注释：**可转债公允价值调整** 公司发行的可转债在估值上涨时，账面上要补记一笔"将来可能要兑付更多股票"的浮亏。它是会计准则下的数字变动，不是真金白银的现金支出——看 AI 公司的"亏损"，先分清是哪一种。

**Claude Duet 上线：Opus 5.5 驱动的 24 小时常驻 Agent（10.22）**

Anthropic 上线 Claude Duet——由 Opus 5.5 驱动的个人智能体，可全天候自主推进任务，主动向你提醒并请求审批，而不只是等你发问。首批面向美国 Pro 和 Max 用户开放候补，支持 6000 多个连接器，共享套餐额度、记忆可直接继承，研究预览期不额外收费。这是 Anthropic 对 Meta Muse、OpenAI Dots 的正面回应：个人 Agent 的战场，从"能聊"转到了"会主动干活"。

**OpenAI 前沿模型登陆谷歌云，三家模型同台（10.21）**

GPT-6 Astra、GPT-6.1 Sol、GPT-6 Luna 以私有预览形式上线谷歌云 Vertex AI Model Garden。企业从此可以用同一份账单调用 Gemini、Claude 与 GPT 三大系列，谷歌云也成为唯一同时托管三家前沿模型的主流云厂商。云厂商的态度变了：与其赌一家模型赢，不如把自己做成所有模型的货架。

**一句话总结：今天的主线是"工业化"——1000 亿融资、14 天交付的数据中心、2 万亿估值、24 小时不打烊的 Agent：AI 正在从一门技术变成一套重资产的基础设施。**

## 二、AI 新元素

**OpenAI 与彼得·蒂尔 4500 万美元押注：用脑植入物治癌症（10.22 深读）**

旧金山初创公司 Coherence Neuro 完成 4500 万美元种子轮，投资方包括 OpenAI Startup Fund、彼得·蒂尔联合创立的 Founders Fund，以及 Lux Capital、8VC 等。联合创始人本·伍丁顿（Ben Woodington）与伊莉斯·詹金斯（Elise Jenkins）披露：公司的 SOMA 设备试图读取肿瘤细胞与大脑之间的微弱电信号，判断癌症是在生长、缩小还是复发，并通过电刺激干预其生长，首个靶点是胶质母细胞瘤。新资金将用于推进该适应症的首次长期人体临床试验、争取 FDA"突破性医疗器械"认定，并扩至胰腺癌等癌种的临床前研发。

> **它怎么赚钱？** Coherence 押的是"持续监测 + 电刺激干预"的闭环器械生意：胶质母细胞瘤会与健康脑组织交织，手术切不干净、复发难以早发现；植入设备把"肿瘤在干什么"变成连续可读的电信号，医生据此调整治疗。上游是电极、植入工艺与 AI 信号解读模型，下游是神经外科中心与肿瘤药企（设备可成为药效评估工具），收入按植入手术与后续监测服务收取，并与药企的临床试验合作分成。它现在只有 3 例人体测试数据，赌的是一个尚未被临床验证的假设——但 OpenAI 与蒂尔同时下注，说明资本开始把"AI 读神经信号"当成下一个平台级入口。

**美团做了个"大众点评版"的 Skill 平台：DeepSkill 收录超 37 万个技能（10.22）**

美团 AI 打造 Agent 技能平台 DeepSkill，已收录超 37 万个经真实任务验证的 Skill，较 9 月初的 13 万增长近两倍。它用大众点评的思路解决 Agent 生态最痛的问题：面对海量技能，用户不知道选哪个、也不敢把数据交出去。平台引入扫描安全分析做准入体检，再用"点评官"数据回流机制让真实使用评价沉淀下来。当 Skill 多到需要一套评价体系，说明 Agent 生态已经过了"有没有"的阶段，进入"好不好"的阶段。

**无界动力开源 MWA™-Phoenix：只用 RGB 的 7B 隐空间世界模型（10.22）**

无界动力发布并开源 7B 参数的隐空间世界模型基座 MWA™-Phoenix，仅用 RGB 输入就在多项仿真与真机榜单登顶：LIBERO-Plus 成功率 94.63%；加入 ILA 后，削皮与擦拭两类真机任务成功率分别升至 40% 与 90%。小参数 + 纯视觉输入跑出这个成绩，对"世界模型必须又大又贵"的假设是一次直接的反驳。

**Claude 64 小时设计 31.8 万种蛋白，17 种达到结合标准（10.22）**

Anthropic 披露：Claude 在 64 小时内生成 31.8 万种蛋白设计，针对 5 种蝎毒神经毒素筛出 211 个候选交由实验室测试，其中 17 种达到结合标准，数据已公开。整个计算阶段耗约 1 万 GPU 小时，由 Claude Science 自主循环完成——但仍属早期科研验证，离临床还远。AI 做科研的节拍变了：不是"帮人算一步"，而是"自己跑完一整轮设计—筛选"。

**云厂商打响 AI 搜索基建战：腾讯元宝搜索开放，阿里"开析"入局（10.22）**

腾讯 10 月 20 日升级元宝搜索，并通过腾讯云向个人开发者与企业开放 Skill、MCP 及 API，索引达千亿级、覆盖 13 个行业、接入 157 个权威信源，测试调用平均约 0.42 秒；阿里云则在 9 月中旬把原 IQS 与 CleverSee 合并，推出企业级 AI 原生搜索引擎"开析"，支持联网、垂域与企业内网搜问。搜索正在从"一个产品"退回"一层基础设施"——谁把检索做成水电，谁就能给所有 Agent 供能。

> 注释：**隐空间世界模型** 不逐像素预测下一帧画面，而是先把画面压缩成一组"看不见的变量"（隐空间），再在这些变量上推演世界会怎么变。算得快、省算力，也更容易学到真正的规律。

**一句话总结：新元素都在补"最后一公里"——让 Agent 能用的技能有评价（DeepSkill）、能懂的世界够便宜（Phoenix）、能查的东西有来源（AI 搜索）、能做的事敢进人体（Coherence）：生态的成熟度，取决于最短的那块板。**

## 三、X 大 V 动态（近 30 天精选）

**黄仁勋（英伟达 CEO）：PC 已死，AI 智能体时代全面爆发**

柏林 GTC 的那句"PC 已死"刷屏之后，真正值得记住的是他给出的账本：十年 AI 性能涨约 100 万倍，摩尔定律只贡献了 100 倍，剩下的一万倍来自芯片、系统软件、算法与工厂散热供电被绑在一起重新设计。他还抛出了 Agent 的五大硬件要素——模型跑在 Vera Rubin NVL72 上思考，Harness 跑在 Vera MGX，知识由 Vera CMX 提供，工具交给 Vera RTX。电脑还在，只是坐在它前面的"使用者"从此包括 AI。

**戴琼海（中国工程院院士、中国人工智能学会理事长）：桌上滑落的水杯，正是 AI 最难学的能力**

在南京的 2026 物理 AI 与世界模型大会上，戴琼海用一个比喻点破转向：水杯从桌边滑落，人可以自然预判轨迹、评估风险并伸手干预，而这恰恰是 AI 最难习得的能力。他指出传统大模型只会"记忆知识、输出文本"，并不懂现实世界怎么运行；世界模型则是给 AI 装上"物理常识加脑内沙盘"，推动它从识别世界升级到理解、预测、推演乃至改造世界。他直言当下不少模型"形似而不神似"。

**姚期智（图灵奖得主、中国科学院院士）：机器人"真干活"才能遇到"真问题"**

姚期智在同一场大会的主旨演讲中提出：只有让机器人进入真实场景"真干活"，才能遇到真实世界中的"真问题"；持续面对并解决真问题，才能推动模型不断迭代。他同时强调具身世界研究属于颠覆性创新，人才是最核心的要素，并呼吁更多青年学者投身这一领域。仿真里的完美分数解决不了真机上的插头插不进——这是把机器人赶进现实的理由。

**沈向洋（港科大校董会主席）：具身智能不只靠 AI，还得有感知、通讯与控制**

沈向洋在现场发言中提醒业界别把具身智能简化成模型问题：它除了 AI 这些核心能力，还需要感知系统、通讯系统与控制系统。这句话的价值在于给当下过热的人形机器人赛道划了一条工程边界——大脑再聪明，身体的神经和血管也得一起长。

**彼得·蒂尔（Founders Fund 联合创始人）：把钱押向"AI 读神经信号"**

蒂尔与 OpenAI 的创投基金同时出现在 Coherence Neuro 的 4500 万美元种子轮名单里。这笔钱投向的不是一个模型，而是一台读肿瘤电信号并用电刺激干预其生长的植入设备，首个靶点是胶质母细胞瘤。当最挑剔的技术投资人开始为"AI + 神经接口 + 临床"付溢价，说明资本寻找的下一个平台，正在从屏幕里往身体里走。

**一句话总结：大 V 们今天指向同一个方向——AI 要离开屏幕：黄仁勋给它造身体，戴琼海要它懂物理，姚期智要它去真场景干活，沈向洋提醒身体还得配齐零件，蒂尔则把赌注压进了人体。**

> 注释：**物理 AI** 让模型不只学文字与图片里的统计规律，还要学会重力、碰撞、摩擦这些真实世界的规则，从而在没见过的场景里也能预判结果。

## 四、GitHub 项目精选

**Vercel durable-harness：让编码 Agent 崩溃后接着跑（10.22 开源）**

Vercel 开源的 durable-harness 解决的是一个很具体的痛点：多数 Agent Harness 把"一轮对话"存在进程内存里，进程中途崩了、函数超时了、服务重新部署了，这一轮就跟着一起死。它的做法是把会话——对话、每次模型调用与工具调用——写进一份持久化日志，崩溃后新进程读日志接着跑，已完成的工具调用不会重复执行。它不改动 Harness 本身，已支持 Pi、OpenCode、Claude Code 与 Codex。为什么有趣：Agent 从本地玩具走向线上服务，缺的正是这一层"断点续跑"——没有它，长任务跑一半就归零，谁也不敢把 Agent 放进生产环境。

**rtk（Rust Token Killer）：在命令输出进上下文之前，先砍掉 90%（84k 星）**

rtk 是一个用 Rust 写的开源 CLI 代理，架在 shell 和模型之间：你敲的每条命令，原始输出在被塞进上下文之前先被压缩一遍，实测最多砍掉约 90% 的噪声（ANSI 颜色码、冗余日志、重复行），无需改动任何配置即可对 Claude Code、Cursor 以及各类终端 AI 助手透明生效，Apache 2.0 许可，作者称已超 400 万次下载。为什么有趣：Agent 每一轮都要把整个上下文重发给模型，日志、文件、网页全在计费；把"洗上下文"从提示词技巧变成一个可安装的中间件，是把成本问题工程化的最直接一步。

**colibri：纯 C 零依赖，让 744B 的 MoE 模型在普通机器上跑起来（38.5k 星）**

colibri 是一个纯 C 编写、零外部依赖的 MoE 推理引擎，口号是"小巧引擎，庞大模型"。它不为每个 token 加载全部专家权重，而是按需从磁盘流式读取当前激活的专家，让 SSD/RAM/VRAM 构成存储层级；实测约 25GB 内存即可启动 744B 参数的 GLM-5.2，支持 OLMoE 系列，能开对话也能起兼容 OpenAI 协议的 Web 服务。为什么有趣：在"显存决定能不能跑"的共识之外，它证明了"放对位置"也能换来量级——本地跑前沿模型的门槛，被拉低到了一台消费级笔记本。

## 五、今日技巧：给常驻 Agent 开 12 小时提示缓存，长任务成本直接砍半（当天上手）

OpenAI 为 Responses API 新增了 12 小时 Prompt 缓存选项（GPT-5.6 及以上可用），常驻 Agent、长任务跨小时复用上下文时，不必再为同一段系统提示重复付费。当天上手三步：

1. **确认资格与接口**：缓存目前挂在 Responses API 上、覆盖 GPT-5.6 及以上模型；Codex 与 Work 对登录用户的缓存永久保留，先确认你走的是这条链路；
2. **把"不变的内容"全部挪到最前面**：系统提示、工具定义、长文档、代码库说明放前缀，把每轮变化的用户输入放最后——缓存按前缀匹配，前面任何一个字变了都会整体失效；
3. **先算账再开关**：缓存写入价是常规输入的 2.5 倍、读取价不变，所以命中次数越多越划算；一次性短任务别开，每天跑几十轮的常驻 Agent、巡检脚本、客服机器人最受益。

适合所有让 Agent 长期驻留、反复读同一批资料的团队——把"重复推理"从默认行为变成可选项，是当下最容易拿到的一笔成本减免。

> 注释：**Prompt 缓存** 模型把你发过的前缀内容临时存起来，下次同样的前缀直接复用已算好的中间结果，只对新内容付费；它按"从第一个字开始的连续前缀"匹配，所以顺序一变就失效。

## 六、AI 论文精选

**《ProtoArena：AI 智能体能发现并利用真实世界的跨组件协议漏洞吗？》（arXiv:2610.17837）**

来自清华、中关村实验室等团队的研究者提出 ProtoArena——一个黑盒、多组件、动态的漏洞利用基准，包含 80 个跨组件漏洞利用环境，覆盖 11 个协议与应用领域、7 类攻击方式；任务主要依据已公开的协议攻击机制设计，智能体在看不到目标源码的情况下，通过受限接口与运行中的系统交互来达成安全效果。它设了三个信息等级，分别考察"照着指引复现""给了机制与拓扑后利用"和"纯黑盒探索"。评测五个大模型后，Claude Opus 4.8 成绩最高：L1 指引下 48.8%，纯黑盒 L3 下只有 12.5%；在 DNSBomb 优化实验中，它把下游响应与查询输入的字节率比放大到超过 17.1 万倍。讲什么：Agent 的安全能力被分成"照做"和"自己找"两档，后一档还差得很远。有什么用：给"AI 自动攻防"提供了一把尺子，也让防御方知道当前真实风险的上限在哪。

**《借鉴研究：面向智能体脚手架的终身演化》（ScholarEvolve，arXiv:2609.40169）**

加州大学圣塔芭芭拉分校与微软团队提出 ScholarEvolve：现有自演化脚手架优化器只能从自己的失败日志里找改进点，因而是被动的——它只能试那些"元智能体本来就会"的修法。ScholarEvolve 加了第二个灵感来源：已发表的学术论文。它自动阅读文献、把其中的方法实现为可运行代码、再用真实任务验证效果，全程不改底层模型权重。结果是在不改一个参数的前提下，把冻结的 Qwen3.5-27B 在 AppWorld Challenge 上的任务完成率从 49.6% 提到 63.6%，在另一个基准上也胜过只用失败日志的对照路线。讲什么：Agent 变强不一定要换模型，也不必只靠试错。有什么用：没有训练算力的团队，可以靠"读论文改脚手架"这条低成本路径持续涨分。

**《用陷阱预期世界模型引导黑盒大语言模型智能体》（PAWM，arXiv:2610.29139）**

以往面向 LLM 智能体的世界模型通常每一步都预测下一个观测，算力开销大、单步信息量却有限。作者的试点发现：世界模型的指导只在"能预见有界多步未来内的陷阱"时才真正有用。于是他们提出 PAWM——不逐步预测观测，而是只在可能出现陷阱时选择性介入，预测即将发生的失败并引导智能体绕开。训练分两阶段：先在标注了"智能体陷阱"的合成数据上做监督微调，再与黑盒模型做 GRPO 联合训练。效果是引导 Claude Sonnet 4.5 在 ScienceWorld 上提升 24.3%、在 WebArena-Lite 上提升 7.7%，优于一众基线。讲什么：给 Agent 配"预言家"，不必每步都算，只要在要出事的那一步开口。有什么用：为不能改权重的闭源模型提供了一条低成本、可插拔的性能提升路径。
