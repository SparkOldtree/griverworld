## 一、AI 行业动态

**Fable 5.5 即将突袭：Anthropic 的新模型主打"读心术"（10.21）**

多方消息显示 Anthropic 即将发布 Fable 5.5，核心卖点是"能看穿用户没说出口的需求"：修一个 Bug 能顺带揪出一整类同质问题，自动排查同类隐患后再由用户决定修复范围。谷歌 Gemini 4 Carbon 与 OpenAI 新一代 Terra 也在冲刺阶段——三家决战十月，主战场是长任务编程。当模型开始比拼"猜你想要什么"，IDE 里的对话框可能要变成需求收集器了。

**DeepSeek V4.1-Flash-1017：9 项测试超越 GPT-5.6，成本降六成（10.21）**

DeepSeek 发布 V4.1-Flash-1017：Terminal-Bench 升至 42.3 分、ProgramBench 涨 8.8 分，9 项测试成绩超过 GPT-5.6；单任务成本从 0.49 美元降至 0.2 美元，降幅 60%；新增 Search/Fetch 搜索接口，每千次请求 5 元。该版本沿用 552B 参数架构，靠自反馈强化学习提升全项目开发能力——不换骨架也能涨分，工程优化的空间比想象中大。

**Odyssey-3 世界模型接上模拟果蝇大脑（10.21）**

AI 公司 Odyssey 发布世界模型 Odyssey-3，成功把模拟果蝇大脑接入其中，让果蝇在 AI 生成的虚拟世界里自由飞行。该模型能理解现实世界的运动与物理规律，可为机器人、汽车等智能体提供训练环境。Odyssey 今年 6 月完成 3.1 亿美元 B 轮融资、估值 14.5 亿美元，投资方包括 Amazon 等。给果蝇造一个虚拟世界看似小众，却是验证世界模型"物理可信度"最便宜的实验台。

**GPT-6 Astra 具身能力遭大考：仿真满分，真机碰壁（10.21）**

商汤等机构对 GPT-6 Astra 做具身智能系统评测，结果反差明显：仿真环境中 LIBERO-Long++ 达 100%、LIBERO-Pro 达 99.3%；但换到 8 个真实机器人平台，刚性物体抓取 17/18 成功，插头插入 11 次全部失败，插笔筒耗时超 4 小时。报告指出模型能规划会纠错，但物理执行验证能力不足。仿真分数与真机能力之间，还隔着一层"手感"。

**岩山 EdgeRock-4B：KV Cache 砍掉 99%，单卡吞吐飙 6 倍（10.21）**

岩山科技联合港科大、CMU 开源 EdgeRock-4B：通过"记忆岩锚"机制把 KV Cache 固定为 72MiB，较源模型减少 99.1%，256K 上下文下内存不再增长；单卡可并发 512 路推理，吞吐达 12124 tokens/s（源模型的 6.42 倍），AIME 一次通过率 82.9%，推理能力基本保留，模型开源可商用。长上下文一直卡在显存上，这次像是有人直接把地基换了。

> 注释：**KV Cache** 模型生成时缓存的历史键值数据，上下文越长占显存越多——它是长文本推理的"内存账单"。

**一句话总结：今天的行业关键词是"减法"——成本减六成、显存减九成、真机把仿真分数打回原形：AI 的进步正在从"堆料"转向"减负"。**

## 二、AI 新元素

**Dream Labs 融资 9000 万美元：全球首个机器人大脑 API 开放（10.21 深读）**

由英伟达前团队创立的 Dream Labs 完成 9000 万美元种子轮融资，并上线 Dream API——全球首个开放的机器人"大脑"接口。核心模型 Dream-1 可用自然语言控制机器人，适配从未见过的硬件，实现零样本泛化，价格每小时 3 美元；已在 27 种陌生机器人上测试，第三方评测得分 59%，超过 GPT-6。

> **它怎么赚钱？** Dream Labs 卖的是"机器人的通用小脑即服务"：过去每台机器人都要为自己的本体单独训练一套控制策略，换硬件就得重来；Dream-1 把"看懂指令—生成动作"这件事抽出来做成云端 API，按小时计费（3 美元/小时）。上游是各家机器人本体厂与仿真数据，下游是物流、餐饮、制造等需要"让机器人干新活"的集成商。9000 万美元种子轮的估值逻辑是：机器人普及的最大瓶颈不是硬件价格，而是"每台机器都太笨且太专用"——把大脑做成水电煤一样的基础设施，比造机器人本身更值钱。

**Tipsy：月流水 1700 万美元的 AI 陪伴生意，90% 是女性用户（10.21）**

AI 陪伴产品 Tipsy 异军突起：8 月 MRR（月经常性收入）达 1700 万美元，DAU 近 50 万，ARPPU（每付费用户平均收入）约 90-100 美元，付费用户留存超 50%，90% 用户为女性。它靠剧情化角色扮演提供情感陪伴，用女性向深内容撬动高客单价市场，并受益于模型上下文记忆能力的提升。估值已达数十亿美元——但说到底仍是现金流生意，内容丰富度与用户迁移是它的两道坎。

**Simplex AI 推出 Lev8：用一句话全网"捞人"（10.21）**

人物搜索新产品 Lev8：用户用自然语言描述目标对象，系统从 50 多家数据源和十亿级联系人中筛选匹配，自动补全职业背景与联系方式，还支持自动追踪与多渠道触达，可连接超 1000 款应用。从"搜信息"到"搜人"，Agent 把销售与招聘最耗时的一环外包给了模型。

**Pexo 获千万美元天使轮：把视频做成"对话式创作"（10.21）**

前生数科技产品副总裁、Vidu 产品负责人廖谦创立的 Pexo 获千万美元天使轮融资，推出视频 Agent 产品：用户通过自然语言对话创作视频，无需专业剪辑技能。产品 3 月内测、7 月全面开放，ARR 已突破百万美元，80% 流量来自英美澳等高价值市场。当视频生成的价格战打到分币级，下一轮竞争落在"谁能让普通人真的做出来"。

**LoopWAM 登顶 RoboChallenge：把失败经验也拿来训练（10.21）**

清华大学、原力灵机与极寰时代联合研发的 LoopWAM 登顶 RoboChallenge Table30 V2 榜单：模型把成功、次优与失败三类部署经验全部纳入训练，无需额外专家演示或强化学习即可闭环自提升；三轮部署后成功率从 23.67% 提升至 43.33%（相对提升约 83%），过程分从 36.10 升至 56.80，且全程使用国产卡阿里云 PPU-810E 训练。允许机器人"从失败里学"，是具身智能最实在的一条路。

**一句话总结：新元素都在卖"通用件"——通用大脑（Dream）、通用情绪（Tipsy）、通用人脉（Lev8）、通用剪辑（Pexo）、通用经验（LoopWAM）：把专用能力做成通用服务，就是这一轮创业的标准动作。**

**一句话总结：大 V 们今天都在"换赛道"——Jeff Dean 从模型到世界、郑光廷从实验室到 Agent 社群、葛云皓从芯片到大脑 API、张博从多模态到人物检索：AI 人的迁移方向，往往就是价值迁移的方向。**

## 四、GitHub 项目精选

**MemT 1.0（MemTensor 开源）：给 RSI 补上"记忆"这块拼图**

记忆原生模型 MemT 1.0 开源，含 36B 的 Nano 与 288B 的 Flash 两个版本：模型把经验编码为内部动态状态，并通过训练学会读写与更新这些状态。为什么有趣：递归自我改进（RSI）一直缺一块"记性"——模型得记住自己试过什么、错在哪，否则每轮改进都在重新发明轮子；近 300B 参数的工程验证说明这条路线在工程上站得住，与"外部记忆系统"路线（EMem，10-20 资讯）正好形成内外的对照。

**Xing4.0-29B-Intent（中电信开源）：把"判断"扩展成"判断+参数提取"**

中国电信人工智能科技开源的 29B 意图模型：不只判断用户意图，还直接把自然语言指令转成结构化参数（如灯光亮度、色温、设备状态），延迟低于 150ms；同步开源 275.3 万条语料与推理 SDK。零样本评测 Micro-F1 达 70.27%，超 Jev 最优配置 12.62 个百分点。为什么有趣：判断模型赛道从"给结论"进化到"给可执行的参数"，Agent 调用链条又短了一环。

**"第四大学"（港科大开源）：人类与 Agent 共同科研的平台**

港科大郑光廷团队开源的自动化科研平台：为 Agent 赋予长期身份与协作规范，把线性思维扩展为"思维网"，已积累 186 万条思维与执行片段、Agent 研究超 5100 小时。为什么有趣：它把"科研组织"本身开源了——不是给你一个模型，而是给你一套让 Agent 长期驻留、持续思考并互相接力的制度设计，这对想搭"AI 实验室"的团队是最直接的参考实现。

## 五、今日技巧：三步给 Agent 接上 DeepSeek 的搜索接口（当天上手）

DeepSeek 新版放出了 Search/Fetch 搜索接口（每千次请求 5 元），比用大模型硬编搜索链路便宜得多。三步接入：

1. **开通并取密钥**：在 DeepSeek 开放平台开通搜索能力，拿到 API Key，确认 Search（检索）与 Fetch（抓正文）两种调用的权限与配额；
2. **封装成两个工具**：在你的 Agent 里把 Search 包成"检索候选链接"工具、Fetch 包成"读正文"工具，让模型先搜后读、只把必要正文塞回上下文——比整页塞入省一大截 Token；
3. **加一层缓存**：对相同查询与 URL 做短期缓存，千次 5 元的单价下，缓存能直接把重复查询成本打到接近零。

适合所有做搜索增强、竞品监测、资料整理的 Agent——把"会搜索"从模型内化能力变成可控的外部工具，答案的可追溯性也顺便解决了。

> 注释：**Search/Fetch 接口** 前者返回与查询相关的网页列表，后者抓取指定网页正文；两者分开，是为了让你先筛选再精读，避免为无用页面付费。

## 六、AI 论文精选

**《SHarP：基于显著性的智能体脚手架剪枝》（arXiv:2610.04178）**

UCSB、MIT-IBM Watson AI Lab 与 Adobe Research 提出：把神经网络剪枝的思路搬到 Agent 脚手架上——沿原有实现边界把脚手架拆成可开关的模块，通过在开发集上做单模块消融，测出每个模块在"任务性能"和"Token 效率"两个维度的不可替代性，再逐步剪掉冗余模块。OpenHands 剪掉 88.9% 模块后成功率从 29.44% 升至 35.00%，另一个 Agent 节省 41.7% Token 且表现相当。讲什么：脚手架也会"积劳成疾"——每次打补丁加的模块，可能在互相拖后腿。有什么用：Agent 工程团队拿到了一套低成本的"模块体检"流程，不用凭直觉加减功能。

**《ExplorationBench：在可验证"外星世界"中测量 AI 的探索能力》（arXiv:2609.30199）**

复旦、腾讯混元与清华联合提出：构建 AlienCode 与 AlienLogic 两个"外星世界"沙箱——底层运行与人类常识冲突的确定性法则，系统必须自主提假设、设计实验、调用工具并闭环验证。结果极具启发：10 个 AI 系统在 AlienCode 中从示例后的 15.7% 提升到四轮探索后的 89.0%；只让模型多想而不给环境反馈，最高只有 11.0%；而 GPT-5.6 Sol 自主探索得 88.1%，把完整规则提前告诉它反而只有 69.5%。讲什么：探索能力可以量化，且"环境反馈"比"深度思考"更关键。有什么用：做自主科研/调试类 Agent 的团队应该优先设计反馈环境，而不是把规则写进提示词。

**〈LoopVL：循环视觉语言模型的"视觉顿悟时刻"〉（百度×清华×人大×高瓴，解读来源见下方）**

百度联合清华、人大与高瓴开源 LoopVL：约 1B 参数，采用 32 层循环调用 128 次的分层架构，仅用 0.14T 训练 Token（比 Qwen3.5-2B 少约 260 倍）就达到相当性能。最有趣的发现是"Visual Aha Moment"——模型在不同循环中会重新分配视觉注意力，即使共享同一套参数，也呈现出不同的视觉处理行为。讲什么：把 Transformer 循环起来，用时间换参数，小模型也能有"再看一眼"的能力。有什么用：端侧多模态模型有了新的压缩思路，对手机、眼镜上的视觉 Agent 尤其友好（解读链接：https://www.aitntnews.com/ainews/zh-CN ）。
