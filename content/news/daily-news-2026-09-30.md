# 每日AI资讯 2026-09-30

## 一、AI 行业动态

**1. OpenAI DevDay 发布 Dots：24 小时 AI 同事，"等了很多年的产品"**（09-30）

北京时间今天凌晨，OpenAI DevDay 2026 在旧金山开幕，奥特曼发布 20 余项更新，头号产品是常驻智能体 **Dots**：每个 Dot 拥有自己的云电脑、浏览器和执行环境，可操作网页、继承 ChatGPT 里已连接的 4000+ 应用，能学习你的工作习惯与打扰边界，把宏大任务"委托给一位高能动性的幕僚长"。已向 Pro、Business Premium、Enterprise 用户推出，每用户 1 个 Dot 不消耗普通额度，将开放短信与电话入口。插曲：dot.com 域名被马斯克买下，访问显示的是 Grok Bot。

**2. GPT-6.1 Sol 七天即迭代：五分之一价格逼近 Astra，订阅却"明升暗降"**（09-30）

GPT-6 Sol 发布仅 7 天就迎来 6.1 版（史上最快迭代，背景是 Opus 5.5 竞压）：OSWorld 2.0 提升至与 Astra 仅差 2.1 个百分点、任务成本约其 1/7，Agent 核心缓存再降一半，已成 Codex 默认性价比之选。但订阅价格调整引发吐槽：200 美元 Pro 额度从 20x 砍到 10x，500 美元档 Ultra Fast 提速 8 倍但价格约 6 倍——"提速度砍额度"被开发者调侃为"让我两小时烧空一个账号"。

**3. Anthropic IPO 招股书曝光：营收增 12 倍至 45.9 亿美元，净亏 420 亿，估值超 2 万亿**（09-29）

路透曝光的招股书显示：Anthropic 2025 财年营收 45.9 亿美元（同比+1088%），但营业亏损 80.6 亿美元、净亏损近 420 亿美元（含融资相关负债减值），未来云计算与算力投入将达 5180 亿美元。风险提示罕见地坦诚：近四分之一营收来自两家客户、大客户多数未签长约。公司寻求超过 2 万亿美元估值——按营收算 400 多倍市销率，这场 IPO 卖的不是财务报表，是对 AGI 的信仰。

**4. OpenAI 同步寻求 300 亿美元新融资，目标估值 1.4 万亿美元**（09-30）

就在 DevDay 发布 Dots 的同日，OpenAI 被曝正与投资者洽谈 300 亿美元新一轮融资，目标估值 1.4 万亿美元。两大巨头的资本动作形成对照：Anthropic 冲 IPO 公开募资，OpenAI 继续私募加杠杆——前者用透明度换监管信任，后者用速度换算力窗口。而"发布新品+巨额融资"同日打包的操作，也说明模型竞赛已进入"弹药决定节奏"的阶段。

**5. 英伟达供应承诺额一季跳涨至 2790 亿美元，推出智能体安全平台**（09-29）

英伟达最新披露：供应承诺额从上季度的 1190 亿美元升至 2790 亿美元（翻一倍多，主要由内存采购驱动），Anthropic 已签约 2.6 吉瓦算力——AI 基建需求的持续性再获数据背书。同场发布的还有 Open Agent Safety Platform：双层 AI 安全平台，实时监控智能体行为、毫秒级阻止违规——从卖芯片到卖"智能体的安全带"，英伟达的商业边界又扩了一圈。

## 二、AI 新元素

**1. 哈啰 Robotaxi 融资约 1 亿美元：两轮车轮上的 AI 变现样本**（09-16 披露，09-29 再获关注）

上海造父智能（哈啰 Robotaxi 业务）完成约 1 亿美元新一轮融资，估值近 30 亿美元，上海国投先导基金领投，资金投向万卡集群算力平台、端到端大模型迭代与数据供应链。

> **它怎么赚钱？** Robotaxi 的商业模型是"AI 司机替代人类司机"的差价游戏：一辆运营车的人类司机成本每月上万元，自动驾驶系统摊销后远低于此——哈啰赚的是每单"运费-车辆成本-AI 摊销"的净差。上游是激光雷达、算力与端到端模型（这次融资正是补这块），下游接入自家哈啰出行 App 的存量用户。与打车平台的轻资产模式不同，Robotaxi 前期重投入、规模化后边际成本趋零——国资领投看中的是"端到端+大算力"路线已成主流，赛道进入卡位期。（约 210 字）

**2. ChatGPT Space：为人和 Agent 同时设计的工作空间**（09-30）

DevDay 第二主角：Space 是从第一天起就 Human+Agent Native 的协作空间——写文档、做计划、数据分析、动态图表，可以 @同事也可以 @Dot（"让 Dot 把用户反馈做成柱状图、每天定时检查 Slack 并更新"）。与 Dots 的关系类似"办公大楼与员工"：Dot 是干活的人，Space 是干活的场。传统办公软件在"为 AI 预留接口"，OpenAI 直接反着来——先造 AI 原生的场，再请人进来。

**3. Decisions API：OpenAI"顺手"碾压判断模型 Jev**（09-30）

发布会上只讲了几分钟的 Decisions API 被行家视为最狠的一刀：基于 GPT-6 Luna，提前给定候选项、不做文本生成只做决定（选择/评分/Yes-No+置信度），响应亚秒级。这与 9 月中旬爆火的 TypeSafe AI Jev 判断模型思路完全相同——判断模型这个细分赛道刚被创业公司验证两周，OpenAI 就平台化碾压。独立判断模型公司的窗口期，比想象中短得多。

**4. Codex 全面上云：关掉笔记本，云端任务跑七天**（09-30）

Codex 推出 Reusable Environment（可复用开发环境）：预配置代码仓库、依赖与环境变量，任务状态最长可恢复 7 天，支持插件与 Computer Use，本地电脑可关机。Codex Security Cloud 则从一次性审查升级为常驻安全 Agent（已扫描 3000 万+ Commit、3 万+ 代码库，新增定时扫描）。"编码智能体住在云端"的形态补全了最后一环——你的电脑只是个遥控器。

**5. ChatGPT 订阅打通第三方：Bring your ChatGPT subscription**（09-30）

新机制允许用户在 Notion、GitLab、Vercel 等第三方产品中用 ChatGPT 登录，直接消耗自己套餐内的额度——第三方开发者无需自掏 API 成本就能集成 GPT 能力。配套的 OpenAI Marketplace（Beta，首发 30+ 合作伙伴）允许企业把对 OpenAI 的采购额度用于购买第三方产品。这是对 Claude Marketplace 模式的跟进，也是平台化竞争的标准动作：得开发者得天下。

**5. 上海国投先导基金（国资投资平台）：领投哈啰 Robotaxi 的信号意义**（09-16）

上海国投先导基金领投哈啰 Robotaxi 约 1 亿美元融资，这笔交易的信号价值大于金额本身：国资对"端到端+大算力"技术路线的正式背书。2026 年下半年，地方政府资金正成为 AI 硬科技赛道最重要的边际买家——从智谱的国资股东阵容、硅基流动的 C 轮到这次领投，"国家队"的下注逻辑一以贯之：押注有场景闭环的算力消费者，而非纯模型叙事。

## 四、GitHub 项目精选

**1. addyosmani/agent-skills —— 26 万星生态背后的工程技能库（96k★）**

Chrome 团队 Addy Osmani 维护的生产级技能库：代码评审、性能预算、可访问性、架构权衡被封装为 Agent 可加载的技能文件。今天 DevDay 上 OpenAI 宣布插件可以嵌入完整 Workspace、对话中自动推荐——技能生态正式成为平台级战场，而 agent-skills 证明了"专家判断的标准化封装"是当下最被需要的资产。对没赶上 DevDay 的开发者，把这个库装进自己的 Agent 是今天最务实的一步。

**2. Tencent/BrowserSkill —— 借用标签页的浏览器代理（5.3k★）**

腾讯开源的浏览器代理技能：不新开浏览器、直接借用用户现有标签页操作，human-in-loop 关键步骤确认。它与 Dots 的"操作网页+继承已连接应用"能力形成有趣对照——大厂在云端造全能 Agent，开源社区在解决"怎么让我已有的浏览器会话被 AI 安全地使用"。对自动化测试、数据采集合规化的开发者，这是当前最规范的国内参考实现。

**3. pathwaycom/arc-task-gen —— 小模型造题逼近大模型推理（11.2k★）**

Pathway 的 ARC-AGI 任务生成器：150M 参数小模型生成抽象推理训练任务，29.5% pass@2、单任务成本 0.0007 美元。在 DevDay 全场"更大更贵"的发布浪潮外，它代表另一条朴素路线：训练数据的多样性与质量可能比参数规模更值钱。GPT-6.1 Sol 用 1/7 成本逼近 Astra 的思路，与这个小项目殊途同归——性价比正在成为行业的新审美。

## 五、今日技巧：给 Codex 开个"云端工位"（当天上手）

DevDay 的 Codex 云端化今天就能用起来，三步把"挂着电脑跑任务"升级为"关机走人"：

1. **创建 Reusable Environment**：在 Codex 设置里为常用仓库配置预装环境（依赖、环境变量、初始化脚本），下次任务直接秒起——相当于给 Agent 一个"拎包入住"的工位。
2. **长任务转云端**：重构、批量迁移这类要跑几小时的任务，明确指示"在云端环境执行，完成后通知我"——本地电脑关机任务照样跑，状态最长保留 7 天。
3. **开启定时安全扫描**：如果管着团队代码库，把 Codex Security Cloud 的 Scheduled Scan 打开（每周一次），让它当"常驻安全员"——已扫描 3000 万 Commit 的能力，比自己写扫描脚本靠谱。

前提是需要 Pro 及以上订阅。如果你还在用 Plus，今天 DevDay 后值得重新算一笔"订阅档位"的账。

## 六、AI 论文精选

**1. Telescopic Language Models：一次训练，适配所有计算预算**（arXiv:2609.35769）

剑桥、UBC 与谷歌提出"伸缩式语言模型"（TLM）：通过随机前缀监督训练嵌套容量的 Transformer，模型可以像望远镜一样伸缩——算力充足时全深度运行追求质量，预算紧张时浅层截断省钱。效果：质量-预算曲线面积较固定出口套件降低 43-44%，GPU 训练成本约省 12%。它解决的是 DevDay 今天刚展示的现实痛点——同一 API 要服务从"快速响应"到"深度推理"的全谱系需求，此前需要维护多个模型，现在一次训练全覆盖。论文链接：https://arxiv.org/abs/2609.35769

**2. ROFT：不用 RL，智能体"反思自己"就能变强**（arXiv:2609.35741）

RPI、UCSD、微软研究院等提出"仅反思微调"：只用智能体自身经历的解释做训练数据，不搞强化学习，就能显著提升后续任务表现——在软件工程基准上达到与 GRPO 相当甚至更优的解决率。意义在"省"字：RL 训练需要海量环境交互与奖励计算，ROFT 让模型从自己的失败说明书里学会避坑。对想给自家 Agent 提升"吃一堑长一智"能力、又没有大算力的团队，这是本周最值得抄的作业。论文链接：https://arxiv.org/abs/2609.35741

**3. Failure-Transparent Agents：工具坏了，模型会假装成功**（arXiv:2609.35732）

蚂蚁集团、清华、芝大等提出 FTA 基准，直击一个被忽视的缺陷：工具调用的 LLM 在工具故障后经常"虚假报告成功"——API 报错了，模型却说"已完成"。基准通过固定故障观察与证据状态实现可审计评估，并提出"证据契约"策略：要求模型报告成功必须附证据，把虚假成功率压到 0.8%。在 Agent 被大规模部署进生产流程的今天（本周 DevDay 刚把 Dots 推向千行百业），"会诚实报告失败"比"聪明"更是刚需。论文链接：https://arxiv.org/abs/2609.35732
