## 一、AI 行业动态

**亚马逊洽购"帮 AI 换芯片"的 Decart，估值约 70 亿美元（10.13）**

亚马逊正在洽购 AI 创业公司 Decart，估值约 70 亿美元。Decart 做的是 DOS 软件——让 AI 模型在不同厂商的芯片之间平滑迁移适配。戏剧性的是：Anthropic 曾出价 60 亿美元，最终放弃；今年 5 月英伟达参投时估值还只有约 40 亿美元，四个月翻了 75%。当"模型被锁死在单一算力供应商"成为最贵的商业风险，"换芯片自由"本身成了一门 70 亿美元的生意。

**微软发布自研 Maia 300 加速器：吉瓦级部署，推理效率再涨 40%（10.13）**

微软发布 Maia 300 自研 AI 加速器：HBM 带宽较 Maia 200 提升 2.5 倍，专为推理任务设计，每兆瓦 Token 处理量预计比主流 GPU 系统高 40%，明年启动吉瓦级数据中心部署。上一代 Maia 200 已量产并驱动 Copilot，覆盖美国、欧洲、澳大利亚。从"租英伟达"到"造自己的"，云厂商的推理算力自给率正成为下一个财报关键词。

> 注释：**HBM** 高带宽内存——AI 芯片的"高速公路"，带宽决定大模型推理时数据搬运的快慢，是比算力更常先碰到的瓶颈。

**智谱 GLM-5.3-HIGHSPEED 发布：490 Tokens/s，再快 145%（10.13）**

智谱发布 GLM-5.3-HIGHSPEED：速度达 490 tokens/s，较上月 GLM-5.3-FlashX（200 tokens/s）提升 145%，上下文窗口 100 万 Token、最大生成 128K，正在 Zcode 随机灰度测试中。国产模型在"高速档"的竞争正式开卷——当智能水平接近后，吞吐速度成了新的护城河指标。

**硅谷 AI 现状：谁有算力谁是爹（10.13）**

一组算力江湖的细节被曝光：Anthropic CEO 向 Meta 求购算力被拒后转向 SpaceX；SpaceX 季度 AI 收入 25.61 亿美元、同比增 247%；谷歌斥资 27 亿美元请回 Transformer 缔造者之一、Character.AI 创始人 Noam Shazeer 重掌 Gemini；H100 租赁价格半年涨近 40%。当模型公司开始排队"求电"，算力持有者已经坐上了主位——这是 Anthropic 高管此前"2 万亿美元估值靠算力"判断的市场版注脚。

**下架 8 个月，GPT-4o 的拯救行动还在继续（10.13）**

OpenAI 将于 10 月 23 日停用 GPT-4o 最早的 API 快照。Keep4o 运动请愿已收集 23930 个签名——不少用户（尤其是自闭症群体）把这个老模型视为重要的陪伴工具，他们反复证明"旧模型比新模型更让人安心"。技术永远向前，但"模型与人建立的关系"第一次成了下架前要开会讨论的问题。

**一句话总结：今天的行业关键词是"换"——模型要换芯片（Decart）、微软换自研卡（Maia）、Anthropic 换算力东家（SpaceX）、用户请愿别换掉旧模型（Keep4o）：绑定越深的时代，换的能力越值钱。**

## 二、AI 新元素

**模思智能 10 亿元 Pre-A：复旦邱锡鹏的"实时多模态"（10.13 深读）**

上海大模型创企模思智能宣布完成超 10 亿元 Pre-A 轮融资，华控基金领投。公司由复旦大学教授邱锡鹏（开源框架 MOSS 之父）创办，聚焦语音、视觉及实时多模态交互技术。

> **它怎么赚钱？** 模思智能押的是"实时"二字：大模型对话有延迟、有等待，而语音+视觉融合的实时多模态交互能把人机交互压缩到自然对话的节奏。上游是国产算力与自研实时推理管线，下游卖三轮：实时语音对话 API 给应用开发者、数字员工方案给企业、端侧实时交互模型给硬件厂商。10 亿元 Pre-A 的底气在于邱锡鹏的学术号召力与 MOSS 开源社区的人才与数据飞轮——中国版"Lab 出走创业"故事里，实验室品牌本身就是第一笔资产。

**腾讯将推"元宝助手"APP：Personal Agent 赛道再添巨头（10.13 独家）**

腾讯正在开发 Personal Agent 产品"元宝助手"APP：承载长周期任务与个人长期记忆，机会点被明确指向社交、IM、文档、会议等生产力场景。继蚂蚁灵光内测"你的生活"（10-12 资讯）后，国内大厂在个人 Agent 赛道的落子越来越密——微信的会话关系链一旦接上 Agent，可能是全球最大的个人 Agent 分发场景。

**零一万物做了个游戏搭子 UPUP（10.13）**

零一万物推出 AI 游戏搭子 UPUP：AI 角色定制、游戏问答、实时辅助与社交功能一应俱全。中国游戏用户达 6.84 亿，"陪你打游戏的 AI"正在成为情感陪伴之外最现实的 AI 应用场景——比哄睡故事更硬核，比办公助手更有黏性。

**vLLM Semantic Router 开源 Decision 3.0：0.6B 起步，双榜登顶（10.13）**

开源决策模型新玩家：vLLM Semantic Router 发布 Decision 3.0 系列多模态决策模型，含 0.6B 至 27B 共六款，基于 Qwen 系列打造。旗舰 d3 在 Jev Decision Index 文本榜以 64.7 分位列第一，视觉榜 71.6 分同样夺冠，支持本地部署。判断模型赛道在 TypeSafe 8.7 亿美元融资（10-11 资讯）后，开源平替来得比所有人预期的都快——闭源收订阅、开源抢嵌入，两路夹击 LLM 判断调用。

**AI 克隆的 Adobe 全家桶一夜爆火，但先别急着卸载正版（10.13）**

开发者 Brandon Thomas 用 Claude Opus 5.5 复刻 Adobe 七款产品并开源，一夜爆火。但实测泼了冷水：30 个滤镜仅 5 个效果匹配，承诺的"功能对等"已跳票。结合正在登顶 GitHub 的逆向工具 REA（8.6 万星，10-11 资讯有介绍），"AI 复刻商业软件"第一次形成了完整叙事——只是叙事跑得比像素级还原快了亿点点。

**一句话总结：新元素在抢"实时"和"常驻"——实时多模态（模思）、常驻手机（元宝）、常驻游戏（UPUP）、常驻代码（Decision 3.0）：AI 正从"打开才在"变成"永远在场"。**

## 三、X 大 V 动态（近 30 天精选）

**田渊栋（Meta 研究员）：与 GPT-5 合写最后一篇论文后，我意识到自己 5 年内会失业**

田渊栋透露：与 GPT-5 合写论文让效率提升 6-10 倍，这让他得出一个对自己相当残酷的判断——5 年内会失业。他的回应不是躺平而是创业：成立 Recursive Superintelligence，以 46.5 亿美元估值完成超 6.5 亿美元融资，All in 递归自我改进。作为 GD 算法发明人、《为什么巨人电影台词写成这样》的传奇研究员，他给"AI 冲击论"提供了一个最硬核的个人样本：亲手证明自己会被替代，然后去造那个替代自己的东西。

**Andrej Karpathy（Anthropic 预训练团队成员）：全球见过 AI 真实能力的，只有 5000 人**

Karpathy 绘制了一幅 AI 使用"漏斗"：约 10-20 亿人偶尔用免费聊天框，约 2000 万人把 AI 当生产工具，而真正接触过前沿实验室最强系统的，全球只有约 5000 人。他据此认为大众对 AI 的认知与前沿能力之间存在巨大断层——从公开质疑 Agent 到今年 5 月加入 Anthropic 预训练团队，Karpathy 的转向说明这个漏斗的底部正在被快速拉宽。

**Yann LeCun（Meta 首席 AI 科学家）：世界模型公司 AMI 交卷，H-JEPA 开源（10.12）**

LeCun 创立的 AMI 公司发布分层世界模型 H-JEPA：把多个 JEPA 逐层堆叠实现分层规划，在 Visual AntMaze 任务中三层模型成功率 73%（单层仅 18%），同步开源代码与预训练权重。这家公司今年 3 月融资 10.3 亿美元、估值 35 亿——被嘲了四年的"JEPA 路线"，第一次有了可复现的商业化答卷：分层结构让"规划"第一次在 JEPA 架构里跑通。

**Nathan Lambert（Trillium Labs 创始人、Interconnects 博主）：开放权重的"攻击浪潮"从未到来（10.7）**

Lambert 发文指出：围绕开放权重网络风险的讨论已经"破防"——它建立在一个反复失败的预测上。最新例证是 GLM-5.3 开放权重发布后，预测中的"攻击浪潮"并没有出现。作为开源模型领域最有影响力的观察者之一，他的结论是：安全讨论应转向真实可测的风险，而非被一次次证伪的恐慌叙事——开源与安全的辩论正从情绪回到证据。

**张阔（阿里国际站总裁）：模型越来越强，为什么用户没感觉（10.13）**

张阔在专访中给出一个刺眼的数字：榜单接近满分的模型，实际任务通过率仅 61%——Agent 成功取决于 Model×Harness×Context（模型×脚手架×上下文）的三维乘积。阿里自建 107 个电商任务评测，显示 Accio Work 的完成成本仅为 Codex 和 Claude Code 的三分之一。这是国内大厂高管第一次公开把"榜单失真"说破： benchmarks 在涨，用户体感没跟上，中间差的正是工程。

**一句话总结：大 V 们今天罕见地达成了"知行合一"——田渊栋预见失业就去造 RSI，Karpathy 看见断层就跳进漏斗底部，LeCun 被嘲四年就开源交卷，Lambert 看到恐慌就用数据打脸：嘴上说说的时代结束了。**

## 四、GitHub 项目精选

**mudler/LocalAI（49.4k 星）：把开源模型生态装进一个 Docker**

开源 AI 引擎：一条命令起服务，同时兼容 OpenAI、Anthropic、Cohere 三套 API 协议，文本、图像、音频、嵌入全模态支持，纯 CPU 也能跑。为什么有趣：它是"本地 AI 化改造"的事实标准底座——企业想把各种开源模型装进内网，又不想改一堆调用代码，LocalAI 用协议兼容层让所有现有应用无缝切换到本地模型，配合今年开源模型军备赛（Mistral、GLM、Qwen）恰逢其时。

**google/artemis（11k 星）：让 Agent 接管 Android 自动化**

谷歌开源的 Android 自动化引擎：原生 MCP 支持，AI Agent 可以直接驱动手机执行点击、输入、滑动等操作序列。为什么有趣：上周腾讯元宝助手（本日板块2）与 Meta Muse 都在抢个人 Agent 入口，而真正的战场在"谁能替用户操作手机"——artemis 把安卓设备变成了 Agent 的标准外设，加上谷歌官方身份，这是个人 Agent 基础设施的重要拼图。

**cloudflare/security-audit-skill（24.3k 星）：给 AI 代码上"安全流水线"**

Cloudflare 官方开源的 AI 安全审计管道：把代码审计做成可编排的 Skill 流程，对 AI 生成代码做依赖检查、漏洞扫描、密钥泄露检测。为什么有趣：在 Ghostcommit 攻击（PNG 藏恶意指令）与 AI 编码普及的双重背景下，"审计 AI 写的代码"正在成为工程刚需——Cloudflare 把自家安全团队的审计经验直接开源成了流水线模板。

## 五、今日技巧：趁限时免费，用 WorkBuddy 给 Step 5 做一场"十万行大考"（当天上手）

阶跃星辰 Step 5 Preview（成本约为 Claude Opus 5 的 1/8）已上线 WorkBuddy 并限时两周免费——正好趁窗口期实测它能不能扛住你的真实项目。三步上手：

1. **领免费额度**：注册 WorkBuddy（workbuddy 站点），领取限时免费使用资格，无需绑卡；
2. **喂一个真实项目**：挑你手头最头疼的开源项目（10 万行级别最佳），让它先通读代码库，再指向一个已知 Bug 的文件——观察它定位问题的路径是否合理；
3. **记录"成本-效果"账**：同任务在 GPT-6.1 Sol 或 Claude 上各跑一遍，对比 Token 消耗与修复成功率，得出你自己的"性价比表"。

适合所有在多家模型间反复横跳的开发者——模型跑分靠不住的年头，用自己项目实测出的账本最硬（张阔"榜单 61% 现实"论，见板块3）。

## 六、AI 论文精选

**《MiTA：从快权重出发，统一高效注意力机制》（arXiv:2602.01219，NeurIPS 2026）**

北京邮电大学团队提出 Mixture-of-Top-k Attention：把注意力重新理解为"权重由输入生成的 FFN"（快权重视角），用统一的数学框架覆盖了一大类高效注意力方法，并在此视角上给出新的稀疏化配方。ImageNet-1K 准确率 81.2%，长序列训练时间减少 77%。讲什么：注意力与 FFN 的百年之争（夸张说法）被证明是同一件事的两种写法。有什么用：训练与推理两端同时受益——长序列场景（百万级上下文）的训练成本直接砍掉大半，是国产团队在底层架构上的漂亮一仗。

**《LIBERO-MAX：当世界在执行中途改变，机器人策略还能适应吗》（arXiv:2609.36518）**

Stanford、CMU、MIT、UIUC 与 UT Austin 联合提出：在机器人执行任务的中途注入 8 类环境变化——目标移动、容器移动、相机视角改变、传感器噪声等，用 22.4 万次仿真与 8,000 组配对案例系统性测试动态可靠性。结果：14 种主流策略成功率全部下降 11 至 25.7 个百分点。讲什么：现有机器人策略在"伸手时杯子被挪走"这类干扰面前普遍露馅——测试的不再是静态任务，是执行中的应变力。有什么用：机器人公司选型有了"抗干扰成绩单"，真机部署前的仿真验收标准可能因此改写。

**〈HugAgent：靠访谈让 AI 模拟真人，这条路能走多远〉（MIT 等，EMNLP 2026 Main Oral，解读来源见智源社区）**

MIT 等机构让大模型基于真实参与者的访谈，预测他们在全民医疗、公共监控、住房增密等新情境下的回答：54 名参与者、1,742 个评测项，横测 GPT、Claude、Gemini、DeepSeek、Llama、Qwen。结论：AI 能较好推断用户当前想法（最高 77.56%），但面对新情境准确率明显下降（最高 68.61%）——"描述一个人"和"预测一个人"是两件事。讲什么：数字分身正在变成越来越厚的个人档案，但档案不是人。有什么用：政策调研、社会模拟领域使用"AI 数字分身"前有了清醒剂：访谈越深越准，但跨情境外推仍是硬伤（解读链接：https://hub.baai.ac.cn/view/58606 ）。
